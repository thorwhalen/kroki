kroki.ISOLATE_SVG = True¶

Whether SVGs are shown isolated (as an image) when a caller does not say. Set it to False to inline every SVG of a notebook (kroki.ISOLATE_SVG = False), trading the protection of thorwhalen/kroki#1 for interactivity (#7).

class kroki.IsolatedSVG(data=None, url=None, filename=None, metadata=None)[source]¶

Bases: SVG

An IPython SVG whose HTML representation cannot restyle the page.

Jupyter frontends (JupyterLab, the classic notebook, VS Code) prefer text/html to image/svg+xml, so they show svg_to_img_html()’s image instead of inlining the SVG. The raw SVG stays available as .data and as the image/svg+xml representation, for exporters that want it.

kroki.bytes_to_image(b, *, isolate_svg=None, svg_display=None)[source]¶

A displayable object for diagram bytes: an SVG for SVG bytes, else an Image.

svg_display picks how an SVG is shown:

  • "isolate": an IsolatedSVG, shown as an image so its CSS cannot leak into the notebook, but without links, tooltips or text selection;

  • "inline": the plain IPython.display.SVG, whose links, <title> tooltips, selectable text and external fonts work, but whose CSS reaches the page;

  • "scoped": a ScopedSVG, inlined with its CSS rewritten to apply only inside it, so it keeps the interactivity and does not leak (#8).

Without svg_display, isolate_svg chooses between "isolate" and "inline", and None for both follows ISOLATE_SVG.

kroki.svg_to_img_html(svg)[source]¶

An <img> showing svg as its own document.

Inlined into a notebook, an SVG’s <style> block is page CSS: mermaid’s, for one, restyles the notebook’s own output text (thorwhalen/kroki#1). As an image the SVG is a separate document, so its styles (and any script) stay inside it.

A root width that is relative (mermaid writes 100%) gives the image no natural width, so the viewBox width becomes its max-width.

>>> html = svg_to_img_html('<svg viewBox="0 0 120 40" width="100%"><style>p{}</style></svg>')
>>> html.startswith('<img src="data:image/svg+xml;base64,')
True
>>> 'max-width:120px' in html
True
Return type:

str

kroki.svg_to_scoped_html(svg, *, scope_id=None)[source]¶

svg inlined, with its CSS confined to it (see kroki.scoped_css).

The middle ground between svg_to_img_html() and a plain inline SVG (#8): links, <title> tooltips, selectable text and web fonts work, as inlined, while every rule of the SVG’s <style> blocks is rewritten to match only inside it, so it cannot restyle the notebook (#1).

>>> html = svg_to_scoped_html('<svg><style>p{margin:0}</style></svg>', scope_id='k')
>>> html
'<svg id="k"><style>#k p{margin:0}</style></svg>'
Return type:

str
